Open-Data Wiesbaden — ein Explorer pro Datensatz PoC

Jede Karte erkennt aus den Daten selbst, was sie kann: Tabelle + Diagramm immer, Karte nur wenn ein Ortsbezirks-Schlüssel vorhanden ist. Keine Konfiguration je Datensatz.

API-Beispiele — so lädt der Explorer Daten: zwei offene Aufrufe, kein Backend, kein Login, kein API-Key

So „pro Datensatz": ein Engine, das jede CSV liest, Spaltentypen rät und die passenden Ansichten freischaltet. Karte erscheint nur bei Geo-Schlüssel (Join auf wiesbaden_ortsbezirke.geojson, Normalisierung + Teilstring). Daten live aus opendata.cloud.wiesbaden.de — kein Backend.
